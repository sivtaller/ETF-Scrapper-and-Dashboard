ETF Dashboard Builder v0.5.0 Saved Views
Replace dashboard.html, dashboard.js and styles.css, then Reload the extension and refresh Dashboard.
Saved Views store search, filters, sorting, hidden columns and rows per page. Views survive browser restarts in chrome.storage.local. Supports Save as new, Apply, Update, Duplicate, Delete, Export and Import JSON. Missing columns are reported when applying a view to a changed dataset.
